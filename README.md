# Erik's Portfolio

Welcome to my personal corner of the web! This repository houses the source code for my portfolio website, where I showcase my projects and document my journey in web development.

I built this from scratch to get hands-on experience with core web technologies, focusing on clean design and smooth interactions.

## Features
- **Responsive Design**: Looks good on desktop and mobile.
- **Glassmorphism UI**: Modern, translucent aesthetic.
- **Project Showcase**: A dynamic grid to display my work.
- **Animations**: Subtle CSS animations for a polished feel.

## Tech Stack
- **HTML5**: Semantic structure.
- **CSS3**: Custom styling with variables and flexbox/grid (no heavy frameworks).
- **JavaScript**: For dynamic content and interactivity.

## Getting Started
Simply clone the repo and open `index.html` in your favorite browser to check it out.
